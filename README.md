# Vendor Performance Data Analytics

## Overview
End-to-end data analysis project using Python (Pandas) and Power BI to analyze vendor performance and inventory trends.

## Tools
Python (Pandas), Power BI

## Workflow
- Data cleaning and preprocessing using Python (Pandas)
- Data transformation and modeling
- Dashboard development in Power BI

## Dashboard Preview
![Dashboard](images/dashboard.png)

## Key Metrics
- Total End Inventory Value
- Average Profit Margin
- Vendor Count
- Inventory Count

## Dashboard Insights
- Comparison of vendor performance based on profit margins
- Analysis of inventory value distribution across vendors
- Visualization of stock changes (increase/decrease)
